# Path-Lab-Test-Price-Comparision

The Path Lab Test Price Comparison System is a healthcare-focused web application that helps users compare the prices of medical tests across different pathology laboratories. The system enables patients to find the most affordable and suitable diagnostic center for their required tests, improving transparency and reducing healthcare costs.

Built using Python, Pandas, NumPy, and Streamlit, the application analyzes pathology test data stored in a custom dataset and provides an interactive interface for users to search, compare, and evaluate test prices from multiple labs. The platform delivers quick results, helping users make informed decisions based on pricing and availability.

### Key Features

 Compare pathology test prices across multiple laboratories.
 Search for specific medical tests instantly.
 User-friendly and interactive Streamlit interface.
 Data processing and analysis using Pandas and NumPy.
 Cost-effective healthcare decision support.
 Fast and accurate comparison results.

### Technologies Used

Python
Pandas
NumPy
Streamlit
Jupyter Notebook (Model/Data Development)

### Objective

The main objective of this project is to provide a centralized platform where users can easily compare pathology test prices, save money, and choose the best diagnostic service according to their needs.
